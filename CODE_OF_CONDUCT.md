# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, keep criticism about the work and not the person, and no harassment of any kind. Issues, pull requests and discussions that break this can be edited, locked or removed.

To report a problem, contact the maintainer through a private message on GitHub (@therealMRBK). Reports are handled confidentially.
