## 安装

需要 Home Assistant 2025.1 或更高版本。

- **HACS：** 把 `therealMRBK/NextFloor` 添加为自定义仓库（类别选「集成」），安装，重启 Home Assistant，然后在「设置 → 设备与服务」里添加集成。侧边栏会出现 *NextFloor* 入口。
- **手动：** 把 `custom_components/nextfloor` 复制到你的配置目录，重启，添加集成。
- **升级：** 通过 HACS 更新，然后重启 Home Assistant 并刷新浏览器标签页（伴侣 App 里：设置 → 伴侣 App → 重置前端缓存）。

平面图、图片和家具包都存在 Home Assistant 的 `.storage` 里。任何数据都不会离开你的安装。

## 画房子

打开**编辑器**标签页（仅管理员）。工具栏放工具，侧边面板始终显示当前选中的对象，底部的提示说明当前工具怎么用。**撤销**（Ctrl+Z）几乎能退回所有操作。

1. **添加楼层。** *添加楼层*会列出 Home Assistant 的楼层（让平面图和 Home Assistant 保持对应），也可以选*空楼层*。楼层表单里设置名称、标高、层高和对应的 Home Assistant 楼层。*移动*和*转 90°* 移动或旋转整个楼层；*带上所有楼层*会把该操作应用到整栋房子。*从 HA 区域添加房间*会按区域各放一个房间作为起点。*复制楼层*会在上面加一份副本，可以连同家具、设备标记和室外区域一起复制；副本与 Home Assistant 解除关联，并按新楼层配置好。
2. **画房间。** *矩形*：拖拽。*自由形状*：逐个点角点，点回第一个角点或按回车闭合，Esc 取消。角点会吸附网格和已有墙体；按住 Alt 可在一次移动中关闭吸附。
3. **描述每个房间。** 名称、*区域*（与 Home Assistant 设备的关联）和*地面*材质。位置和尺寸可以直接输入。拖动角点手柄改变形状；边上的 **+** 可以加角点。
   *＋ 房间内的区域*用于添加属于这个房间但没有独立墙体的 Home Assistant 区域（阅读角、开放式厨房）：它们的设备会算作这个房间的。*地暖*指定哪个温控器、阀门或开关在供暖时让地面发亮。矩形房间会显示墙到墙的内侧尺寸。
4. **墙体。** 墙由房间的边生成。每条边有高度、厚度、一个把它拆成多段的剪刀按钮，以及用于开放边的*无墙*。降低高度就变成女儿墙或吧台。独立隔断用*墙*工具画（按住 Shift 保持直线）。拆开的边每一段可以有自己的厚度。楼层表单里的*闭合缝隙*能合上发丝级的缺口。边（或独立墙）上的 **◠ 弧形**会打开*拱度*输入框：输入中间凸出多少（负数向房间内弯），然后按*弯曲*。共用整面墙的房间会一起弯，门窗跟着走；只接触墙的一部分的房间，或立在这面墙上的独立墙，保持直。门窗太宽、弯得太深时，弯曲会停下并给出提示。
5. **门窗。** *门窗*工具，点一下墙，选类型（门、入户门、双开门、窗、双窗、阳台门、法式门、车库门、玻璃墙）。设置宽度、距墙角的位置、窗台高度和高度；可以换合页侧或开启方向。样式选*自动*时，外面用入户门、里面用房门。
6. **楼梯与洞口。** *楼梯*工具在你拖拽的位置画楼梯；它沿长边方向走。可以选形状（直跑、四分之一转、带平台的 L 形、半转、带平台的 U 形、螺旋），左右转向，结构可选实心、梁式、中柱或悬挑，有无踢面和栏杆。踏步跟随楼层高度；表单会显示踏步高、踏步宽和步距，楼梯不舒适时会提示。*向下通往*让楼梯通向一个不必画出来的地下室。楼梯只会在踏步净空不足 2.2 m 的地方打通上层楼板；*楼梯与栏杆*包里的楼梯会切掉整个占地范围。*楼板洞口*可以切出其他任何洞（中庭、井道）。
7. **底图。** *底图（平面图图片）*在平面图后面放一张图片；可以移动、缩放、旋转和摆正，按已知长度设定比例，然后照着描。
8. **锁定。** *平面图*锁可以防止房间、墙体、门窗和室外区域被误移动；单件物体可以用*固定*锁住。

**旁边的 3D** 会在你绘制时把 3D 模型显示在平面图旁边。*设为本层/本房间的起始视角*会把当前 3D 相机记下来供以后使用。

## 面积与纸质平面图

房间表单会显示该房间的*居住面积*（按德国《居住面积条例》计算：净高 2 m 以上全计，1–2 m 之间计一半，低于 1 m 不计）；车库、地下室和设备间按名称排除，也可以用*计入居住面积*手动决定。楼层表单会汇总该层和整栋房子的面积，*🖨️ 打印平面图 / PDF* 会以 1:100 打开每一层，带尺寸标注和面积表——可以直接打印，或在打印对话框里存为 PDF。

## 便签

在平面图上右键（或长按）某个位置，选 *✎ 在此添加便签*：输入文字，也可以设定到期日。便签在所属楼层的 3D 视图里显示为黄色标记（到期后变橙色）；点一下显示全文，搜索也能找到。

## 检查平面图

编辑器侧边面板顶部的 *✓ 检查平面图* 会按楼层列出缺失或不对的地方：房间没有区域、区域没有房间、房间里的设备还没放置、房间重叠、门窗不在墙上，以及指向 Home Assistant 已不存在实体的关联。蓝色按钮一键修复（照常可以撤销），*显示*定位到对应位置。

## 布置家具

用*家具*工具，点一个房间，从右侧素材库里选。新家具会出现在房间中央。

- 素材库有分类（灯具、客厅、餐厅、厨房、卧室、卫浴、工作、车位），然后是家具包。搜索支持德语和英语名称、包名，以及任意顺序的多个词。
- **家具工作室：** 素材库顶部的 *🛠️ 自己做一件*。选模板（柜子、搁架、灯、设备），用厘米输入尺寸，设置门、抽屉、层板、拉手、底座和颜色；正视图会跟随每一次修改。*放入平面图*会把它存进*自有家具*包（素材库里也能看到）。选中工作室做的家具，按*在工作室中修改*可以之后再改——平面图里的每一个副本都会采用新尺寸。
- 拖动移动，拖角点改尺寸，用旋转手柄或直接输入位置、尺寸和角度。*镜像*左右翻转，*复制*复制一份，*固定*锁定，*移到楼层*把家具放到另一层的同一位置。
- 带电气符号的家具可以关联设备（见下文）。灯是背后有光源的家具；灯具分类里有十二种。
- **点位布置：** 房间的*点位*会按行列铺一组灯，全部跟随同一个光源，一步即可撤销。
- **素材库：** 家具按类型排序（座椅、床、厨房……），带图片和尺寸；同一模型的多个尺寸是一张卡片，用尺寸标签切换。选中房间后，能放进去的排在前面（*适合……*），*显示所有房间*可以取消这个筛选。可按 ⚡ 可关联、💡 带光、🌳 室外筛选；★ 收藏和最近使用排在最上面。
- **改尺寸：** 桌腿、扶手、台面、拉手保持真实尺寸，只有中间部分伸缩。
- **墙面视图（▣）：** 在房间的墙列表里，*墙面视图*会正面显示这面墙及其门窗、靠墙的家具；可以拖动，或直接输入距离和高度。
- **灯开关与插座**（智能家居包，1～4 联）：每个按键各自绑定实体；它控制的东西亮着时按键会发光。
- **雨棚、窗帘、卷帘、投影幕、平移门：** *随……移动*选择它们跟随的 cover 实体。
- **沙发：** 内置沙发的*形状*可选直排、L 形（可镜像成另一侧）或 U 形。
- **相框**（*相框与画*包）：在表单里上传照片、填图片地址（/local/…），或选一个图片/摄像头实体；设置卡纸以及照片是否铺满。
- **仅当……时显示：** 任何家具都能等某个实体——圣诞树只在某个辅助实体开启时出现。多个状态用逗号分隔，也可以反过来写；编辑时始终显示。
- **移动标记：** 靠得太近的设备标记可以在表单里推开或抬高；设备本身不动。
- **坡屋顶下：** 阁楼房间里的吊灯和悬挂物有 *📐 升到坡屋顶底*。
- **图层：** 在表单里标为*图层*的楼层（树木、装饰）会在 3D 视图顶部多一只眼睛，控制显示或隐藏。
- **楼层电表：** 楼层表单里的*楼层电表（功率）*可以为该层单独指定一个功率传感器。数值显示在楼层标签上，本层视图里的房屋卡片会显示它及其占全屋的比例。

## 连接设备

在房间表单的**设备**区域会列出该区域内的 Home Assistant 设备。标签页有*本区域*、*其他区域*、*无区域*；可按名称搜索。每一行有：眼睛（在 3D 房间面板里隐藏）、*Aa*（自定义名称）、星标（加入房间面板但不放置）、*放置*。

- 放置一个灯就把变成灯具。*灯或开关*指定光源；*颜色和亮度来自*用于继电器控制灯泡的情况；*3D 发光强度*调整光晕；*切换前询问*防止误触；*3D 标记*决定它上方的标记。
- 电器家具（电视、冰箱、洗衣机……）会自动在同一区域找到对应实体（"自动"）。电视会显示正在播放的应用的颜色和标题；*电视背后的光*设置或关闭氛围灯。功率传感器会显示瓦数。每件电器都在状态旁显示功率，运行时状态灯会亮。
- **多灯泡灯具：** *灯泡 2、3……* 添加同一个灯具的夜灯或氛围环；主灯关着时灯具用它们发光。
- **卷帘：** 窗户的*卷帘类型*可选室外卷帘、叶片随倾斜角变化的百叶、或室内卷帘；*第二卷帘*覆盖宽窗的右半部分；*收藏位置"My"*会在卷帘快捷菜单里加一个 **My** 按钮。
- **3D 打印机与热泵：** 把家具包里的打印机或热泵关联到其设备的任意实体；实时卡片会显示打印状态（图片、进度、剩余时间、层数、温度、耗材——打印件会在热床上长出来）或热泵状态（模式、出水/回水、功率、热量、COP）。
- **割草机器人：** *Garden 2* 里的割草机或充电座关联到 `lawn_mower` 后，割草时会在草坪上按路线行进。
- **宠物：** 宠物的*房间传感器*（Bermuda、ESPresense）让它只在真实所在的房间走动。
- 实体输入框可搜索：输入名称的一部分再选。NextFloor 从不因为关联而切换任何东西。
- **车位**（素材库*车位*分类）：*车辆*选择车型，*"车在位"传感器*决定何时显示，关联车的任意实体后，NextFloor 会在车的设备上找到电量、续航、插枪、门锁和空调。
- **收藏与自定义按钮**（设置区域的*收藏*）：场景、脚本、自动化、开关和按钮，用于中央菜单；自定义按钮可以打开仪表盘路径、实体详情、服务调用或 browser_mod 弹窗。*电台或播放列表*添加音箱预设。预设可以限定只在某些音箱上。**自定义告警**能把任意实体变成告警栏的一行（状态、多个状态用逗号、或 `<20` / `>80`），带文字、房间和颜色。**"今日"的日历**决定*今日*卡片的内容。

## 室外、屋顶与能源

- **室外：** 拖出草坪、露台、小径、车道、泳池、花坛、野地、绿篱、围栏或凉棚。*高度偏移*升降，*坡度*倾斜，*显示轮廓*切换发光边线，*从下方区域挖空*可以挖洞（池塘）。区域可以关联 Home Assistant 的*区域*（设备会归入室外，标记点可打开它）；泳池、池塘和花坛可以在标记上显示水温和水泵。绿篱和围栏可以设置高度。庭院灯和路径灯来自素材库，会照亮这些区域。
- **室外面板：** 只要有设备位于房间之外，3D 视图上方的栏里就会在楼层按钮旁出现 **🌳 室外** 标签。它会打开房屋视图，并显示一个类似房间面板的面板，列出花园里的设备。位于屋顶上方或某个房间上方但属于室外的设备（比如气象站），在表单里选*属于室外*：它就不再计入下方房间，并出现在室外面板里。仪表盘卡片上也会显示这个标签及其房间按钮。
- **屋顶：** *屋顶*工具从房间生成屋顶段（形状、屋脊方向、檐口、坡度；拖动移动，角点改尺寸）。简单屋顶形状在设置里。屋顶窗放在屋顶段上，可以带卷帘和门磁。山墙、四坡和半四坡的屋顶段在屋脊两端可以有不同的收头，斜着接入大屋顶的翼楼会形成天沟。屋顶段可以用*转向（°）*绕中点旋转（比如斜向的翼楼）。半四坡的端头有滑杆，决定坡从多高开始。平屋顶上的光伏板可以装在东西向支架上，坡屋顶上的可以装在自己带倾角的支架上。
- **门窗（补充）：** 门可以关联智能锁（点门即上锁/解锁，未上锁时发光）；窗可以选择窗台和窗台板，可以排除在雨水告警之外，位于地面以下时会自动加采光井。
- **能源：** 清单会要求一块光伏板阵、一个电表和一个逆变器（电池和并网可选）。光伏板阵放在朝向最好的屋面段（会用指南针）、花园里或墙上；设置行列、横向/纵向。电表、逆变器、电池、充电桩都是在这里放置的设备；能量平衡的字段默认"自动"，*从能源仪表盘接管*会读取你已有的配置。**线缆路径**画出线缆真实走向（光伏到逆变器、电池、逆变器和电网到房子、分表）：*画路径*，在平面图上点几个点，穿过楼板时切换楼层，然后*完成*；功率流动会沿着路径而不是弧线，*显示为线缆*会把它画成看得见的线缆。*燃气表*和*水表*会把读数加入平衡。

## 指南针与地图

在**设置**里：

- **指南针。** 一个表盘显示北在哪（从上方顺时针的度数）。阳光、风和屋顶朝向都跟随它。如果南北反了，按 **交换南 ↔ 北**；绘制、屋顶段和光伏板阵都保持不变，只改方向。也支持四分之一转和任意角度。
- **真实地图。** 默认关闭。打开后，编辑器里平面图下方、3D 里房屋下方会垫一张淡化的地图（OpenStreetMap，或用你自己的 `https://…/{z}/{x}/{y}` 瓦片地址）。它从 Home Assistant 的位置开始；设置可见度和细节，用箭头移动，直到房子落在它自己的地块上。浏览器直接从地图服务器加载瓦片，而且只在地图打开时加载。
- 这里还能设置：墙厚、网格、长度单位（米或英尺英寸）、屋顶形状、天气实体与效果、雨水告警（可选你自己的雨量传感器）、停电传感器、阳光光斑，以及房屋背后的自定义背景（颜色或图片）。

## 使用 3D 视图

- **移动：** 拖动旋转，滚轮缩放，右键或双指平移。顶部有楼层和房间按钮，点击相机飞过去；*返回*或 Esc 向上一层。
- **外观：** 画质 *自动 / 平板 / 高*；主题 *Neon / Blueprint / Day* 加一个强调色；标记 *无 / 重要 / 全部*。
- **底部开关：** *高墙 / 剖切 / 斜切*、*实心*、*分开 / 叠放*、*屋顶保留*、热图（*温度、湿度、CO₂、数值*）、*房间名*、*天气*、*功率流动*、*卡片*。
- **热图：** 除温度、湿度、CO₂ 外，热图选择器还有**发霉**（每个房间最冷墙面的风险）、**数值**（含通风提示）和 **Wi-Fi**（每个接入点的覆盖、它带的设备、离线的网络设备）。温度色阶在 5 月到 9 月用夏季刻度。
- **墙：** *斜切*会斜着切墙，前面半高、后面全高，像玩偶屋；切面随相机转动。*实心*用不透明的彩色墙代替玻璃；在开敞房间里，相机前方的墙会降低。颜色在编辑器里设：*设置 → 外墙颜色 / 内墙颜色*，以及每个房间的*内墙颜色（本房间）*。*实心*和*斜切*可以同时开。
- **房间面板：** 灯（开关、亮度、色温、色点、*全部关闭*）、卷帘、媒体、传感器、场景。点灯标记即开关，长按打开快捷菜单，卷帘打开自己的菜单。音箱和电视打开带播放/暂停、跳过、音量、输入源和预设的快捷菜单。场景排在最前；*＋ 保存氛围*把房间当前的灯光存成一个氛围，可再次套用或（→）套用到别的房间。面板还会显示房间最近 24 小时的温度和什么时候该通风。
- **中央菜单（星标）：** 本层或全屋的所有灯和卷帘，加上你的收藏。⚙ 里的 *★ 菜单常开* 会让它在这台设备上保持展开且更大；自定义按钮在对应实体开启时发亮。**搜索（放大镜）：** 输入设备或房间名，相机飞过去。
- **告警：** 烟雾、燃气、CO、漏水、报警面板，以及下雨时开着的窗，会以横幅提示；点一下跳进对应房间。报警触发时会指出是哪个传感器触发的，并让那个房间脉动。
- **小屏幕：** ⚙ 里的 🔍 让自适应视图更近；*🎥 保持相机*在切换楼层时保持方位、高度和距离。
- **今日：** 选好日历后，右上角的卡片会列出今天的日程和今明两天要收的垃圾桶。

## 实时功能

内置且免费，只需要你已经有的设备。

- **房屋外的天气：** 雨、雪、冰雹、雨夹雪、雾、带阴影的云、闪电、日月，由天气实体和指南针驱动。晴朗的夜晚会出现星星；下雪时地面会积白，下雨时地面会变湿。
- **阳光与阴影：** 房子按真实太阳投下阴影（设置里的*阳光与阴影*，在*平板*画质下默认关闭）。在视图选项（⚙）里打开 *☀ 时刻* 后，3D 视图下方的 **☀** 开关会打开一个今天各时刻的滑杆：阳光光斑、阴影、天空和 *Auto* 外观都跟随所选时刻；再点一下回到当前。
- **功率流动：** 粒子从光伏板到逆变器、房子、电池和电网；一张玻璃卡片显示能量平衡和自给率。
- **电视屏幕：** 正在播放的内容，用应用的颜色，加氛围灯。
- **声音：** 每个正在播放的音箱或电视上方有一张带封面和控制的卡片；声波用应用的颜色；多房间组合用一条线连起来。
- **汽车：** 车位上方一张卡片，带电量环、续航、充电功率、插枪状态、车内温度，以及门锁、空调和充电按钮。离家时会显示距家多远；显示出发时间，并对开着的门和后备箱告警；插在充电桩上时会挂在充电线上。
- **能源：** 房屋卡片用柱状显示最近七天，并固定在打开的楼层上方；家用储能在正面显示电量。
- **一键全关：** 房间面板里的 *⏻ 全部关闭*，或顶部栏里针对当前楼层的 *⏻*，会关掉灯、开关、风扇和媒体。*↶ 撤销*可以在十秒内全部恢复。
- **扫地机器人：** 放在平面图里的 `robot_vacuum` 以前只会沿 3D 视图为它所在房间编造的路线行驶。当机器人所在的集成把地图挂到相机上（`vacuum_position`、`charger`、`path`，NarwalIntegration 的地图卡片就是这样），它显示的就是真相：机器人站在它报告的位置、朝向它报告的朝向，地面上留下它真正走过的轨迹；基站也画在机器人报告的位置。详见下方「扫地机器人上平面图」。

### 扫地机器人上平面图

相机是自动找到的——任何属性里带 `vacuum_position` 的 `camera` 都行，不需要选择。视图无法知道的是机器人的网格怎么落在你的平面图上：机器人按自己的格子计数，平面图按米。

把两个坐标系绑起来：在平面图上选中机器人的基站，按「用机器人现在的位置标定」，让机器人开出 1.5 m 以上，然后在平面图上点一下它此刻站的地方。基站是锚点——平面图知道它站在哪，相机知道它和机器人在网格里的坐标——所以点一次就够，其余（位姿、轨迹、基站）都会跟着算出来。

只有两个点无法区分镜像和旋转（两种都能让它们准确落位），所以当地图的 y 轴沿平面图 −z 方向增长时，要勾上「镜像」，否则房间会反过来。这两个点存在 `settings.vacuum_map` 里（`a`/`ga` 与 `b`/`gb`，外加 `mirror`）；没有它，视图仍然画自己编的路线。

轨迹的精细程度取决于集成发多少点：把 `path` 裁到几百点的地图卡片只能给出粗糙轨迹，发得多的就细。

机器人回充十分钟后轨迹会淡出，地面上不会一直留着昨晚的清洁痕迹——已经扫完的记录留在时间线（⏪）里，它保存一整天的变化。\n\n这些属性名来自「扫地机地图卡」这套既成约定，不属于某个品牌：小米系地图提取器（Roborock、Viomi、Roidmi、Dreame、Ijai）、Roborock 集成、NarwalIntegration 都用它；机器人按毫米而不是按地图格子报坐标也一样能用——尺度由那两个点定。前提是集成要把它们作为属性暴露出来，有些需要你显式配置（地图提取器要在 `attributes:` 里列出 `vacuum_position` 和 `path`）。

## 四处走动

- **在屋里走（🚶）：** 在打开的楼层上以视线高度行走。拖动环顾，W A S D 或方向键行走（Q/E 转向），滚轮走一步，平板上用右下角的摇杆。✕ 结束。
- **时光回溯（⏪）：** 从 Home Assistant 的历史回放最近 24 小时或 7 天：灯、卷帘、门窗、门锁、媒体、机器人。时间条标出每一次变化；按每秒 1 分钟、10 分钟或 1 小时播放，或拖到某个时刻。*实时*回到现在；在过去时不会切换任何设备。
- **3D 锁定（🔒）：** 在这台设备上关闭旋转、缩放和平移；点击设备仍然有效。
- **时钟：** 顶栏的 🕒 会在视图一角放一个大时钟。
- **外观 *Auto*：** 太阳在时用白天外观，日落后用霓虹。
- **房屋卡片：** 屋顶上方的能源卡用曲线显示最近 24 小时（光伏为面积，用电为线）。

## 家务与宠物

- **垃圾桶**（花园包，四色，120 和 240 升）：在表单里选*收运日期（传感器）*，例如来自 Waste Collection Schedule，或一个带天数或日期的传感器。前一天和当天垃圾桶会发光并显示标记。
- **信箱：** 选*邮件传感器*（例如投信口的门磁）；有信时发光。
- **植物：** *土壤湿度（传感器）*和*低于多少算缺水（%）*；低于该值时植物发光。
- **洗衣机、干衣机、洗碗机：** 如果设备在 Home Assistant 里有剩余时间传感器，标记上会显示"还剩 25 分钟"。
- **宠物**（宠物包：猫、狗、兔子）：在自己的房间里走动，绕过家具，中间会休息。

## 播报

*"开饭了！"* —— 该听到的房间就会听到。

- **从房间发：** 房间有音箱时，房间面板会有 **📢 播报** 区域。点一句预设，或自己输入；房间的音箱会念出来。自定义句子在*编辑器 → 设置*里（每行一句）。
- **房间的音箱：** 优先用房间表单里指定的，其次是放在房间里的音箱，再其次是语音助手（Voice PE 等卫星设备）、Echo，或该区域的音箱。关着的电视或音箱不会被自动选中。语音卫星会用自己的提示音播报，Echo 以真正的播报方式（Alexa Devices 或 Alexa Media Player），支持的音乐箱（Sonos 等）会压低音乐并在之后继续播放；其他音箱通过 Home Assistant 的文字转语音朗读。
- **按房间设静音时段：** 在房间表单里设，例如婴儿房 20:00–07:00。发往多个房间的播报会跳过该房间；只发给它的播报仍会通过。
- **在屏幕上：** 每个打开的 NextFloor 页面（面板或卡片）都会在大字显示消息、播放柔和提示音并朗读——旧平板就变成了播报音箱。在 ⚙ → 📢 里给屏幕起个名字（比如*走廊*），就能单独给它发；也可以在那里取消勾选让它保持安静。浏览器只有在页面被点过一次之后才允许播放声音；在 Fully Kiosk 里打开 *Autoplay Audio*（Web Content Settings）。
- **在自动化里：** 动作 **NextFloor：播报**。

```yaml
action: nextfloor.announce
data:
  message: "有人按门铃！"
  rooms: [Kitchen, Living room]   # 按名称、房间 id 或区域 id；省略则发给所有带音箱的房间
  on_screens: true                # 打开的 NextFloor 屏幕也会显示并朗读
  screens: [Hallway]              # 可选：只发给这些屏幕
```

`floor` 限定某一层，`on_speakers: false` 让音箱保持安静，`tts_entity` 指定声音。该动作会返回哪个音箱说了、哪些房间被跳过（以及原因）。

## 给自动化用的传感器

NextFloor 会向 Home Assistant 添加传感器：*开着的门窗*和*开着的灯*，有全屋和每层两种（在设备 *NextFloor* 下）。它们统计平面图里的门磁、车库门、设备标记和灯具，属性 `entities` 列出哪些开着——例如布防时发通知 `{{ state_attr('sensor.nextfloor_open_windows_and_doors', 'entities') | join(', ') }}`。

## 仪表盘卡片

在仪表盘的卡片对话框里添加 *NextFloor*（`type: custom:nextfloor-card`）。可视化编辑器可设置楼层、尺寸、外观、强调色、墙体、画质、下方楼层、标记、热图、功率流动、卡片、卡片内开关、房间按钮、中央星标、房间名、能源数值、点击看房间详情、全屏、楼楼层分开、屋顶淡出、告警、场景按钮和天气。较新的选项：`central_open`（星标菜单常开且更大）、`keep_camera`、`readable`（更高对比度和更大字号）、`zoom`（0.6–2.5）和 `today`（今日卡片，默认开）。YAML 里用与编辑器显示相同的名字。

## 墙上平板

卡片的展示模式部分会在空闲后回到起始视图，夜间调暗（按太阳或时间段，彩色效果休息），可以像屏保一样缓慢转动相机，还能显示跳转到其他仪表盘的按钮。Fire 平板一类的设备请用*平板*画质。

## 自己的模型与家具包

- **扩展标签 → 家具包：** 以文件形式导入自己的家具包，或直接粘贴 JSON，也可以删除自己导入的包。格式见 [packs.md](packs.md)（德语）。
- **扩展标签：** 为车辆位置上传自己的 `.glb` 模型。浏览器会把它转正、减重、去掉贴图并标记漆面；文件保存在你的 Home Assistant 上（仅管理员，最大 12 MB）。见 [models.md](models.md)。
- **家具包**随集成自带（40 个包、近 800 个模型），无需配置。自己的包是 JSON 文件，格式见 [packs.md](packs.md)。演示站有一个模型展厅，可以实时查看每个模型。

## 备份

*🔗 分享视图*会把房子保存成一个小 HTML 文件，在没有 Home Assistant 的任意浏览器里都能打开（通过在线演示，不含设备和实体）——用来给别人看。

*📌 保存当前状态……*用名字保存平面图（自动恢复点被清理时，命名的版本会保留）。恢复点上的*对比*会按楼层列出它与当前平面图的差异。

**Sweet Home 3D** 的平面图（.sh3d，5.3 及更新版本）可以在*备份 → 导入*里直接载入：层级变成楼层，房间变成房间，门窗落在它们各自的墙上，独立墙保持独立。家具不会被导入。CAD 导出的 **DXF** 图纸（.dxf）同理：闭合多段线变成房间，线条变成独立墙。

编辑器*备份*下方：平面图的**导出** / **导入**、**作为模板分享**（不含个人设备数据）、**完整备份**（平面图、图片、家具包打成一个文件）和**恢复完整备份**。做大改动前先备份。

平面图也可以手写、从其他程序转换，或让 AI 照着你的户型图生成：格式说明和现成的提示词在 [plan-format.md](plan-format.md)。

## 疑难排查

- **房间里缺设备：** 房间需要设置区域，且设备要属于它（设备或实体）。否则用*其他区域*或*无区域*。
- **升级后面板还是旧的：** 刷新标签页；伴侣 App 里重置前端缓存并完全关闭 App。重启 Home Assistant 对这种情况没用。
- **家具显示成灰盒子：** 它的家具包没装；重新导入即可恢复。
- **汽车不显示：** 检查*"车在位"传感器*；没有传感器时会一直显示。
- **光伏板落到屋顶的另一侧：** 检查设置里的指南针。
- **平板卡顿：** 画质调*平板*，关掉天气和功率流动。
- **保存失败：** 只有管理员能保存；提示会指出 Home Assistant 拒绝的字段。
