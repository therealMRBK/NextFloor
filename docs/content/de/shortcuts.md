---
title: Tasten und Gesten
description: Jede Taste und Geste von Editor und 3D-Ansicht an einem Ort.
---

Drücke im Editor `?` für das Tastenblatt. Diese Seite listet, was die Dokumentation kennt.

## 3D-Ansicht

| Aktion | Maus | Touch |
|---|---|---|
| Drehen | ziehen | ziehen |
| Zoomen | Mausrad | Zusammenziehen |
| Verschieben | rechte Taste, ziehen | zwei Finger |
| Lampe schalten | Pin anklicken | Pin antippen |
| Dimmen | | auf dem Pin wischen |
| Schnellmenü mit Farben | langer Druck | langer Druck |
| Einen Schritt zurück | Doppelklick auf leere Fläche; auf Wunsch ein kurzer Rechtsklick | Doppeltipp auf leere Fläche |
| Raum oder Gehmodus verlassen | `Esc` | ✕ |

## Durchs Haus gehen

| Taste | Aktion |
|---|---|
| `W` `A` `S` `D` oder Pfeile | gehen |
| `Q` / `E` | drehen |
| Mausrad | ein Schritt |
| Stick (Tablets) | steuern |

## Editor

| Taste | Aktion |
|---|---|
| `Strg` + `Z` | rückgängig |
| `Enter` | eine freie Form schließen |
| `Esc` | die aktuelle Aktion abbrechen |
| `Alt` | das Einrasten für einen Zug ausschalten |
| `Umschalt` | eine freie Wand gerade halten |
| `?` | das Tastenblatt öffnen |
| Rechtsklick oder langes Tippen | eine [Notiz](plan-tools.md#notizen) anheften |

## Diese Dokumentation

| Taste | Aktion |
|---|---|
| `Strg` + `K` oder `/` | Suche |
| `↑` `↓` `Enter` | ein Ergebnis wählen und öffnen |
| `Esc` | die Suche schließen |
