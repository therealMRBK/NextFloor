Press `?` in the editor for the sheet of keys. This page lists what the documentation knows about.

## 3D view

| Action | Mouse | Touch |
|---|---|---|
| Turn | drag | drag |
| Zoom | wheel | pinch |
| Pan | right button, drag | two fingers |
| Switch a lamp | click the pin | tap the pin |
| Dim | | swipe on the pin |
| Quick menu with colours | long press | long press |
| Go one step back | double click on empty space; optionally a short right click | double tap on empty space |
| Leave a room or walk mode | `Esc` | ✕ |

## Walk through the house

| Key | Action |
|---|---|
| `W` `A` `S` `D` or arrows | walk |
| `Q` / `E` | turn |
| mouse wheel | one step |
| stick (tablets) | steer |

## Editor

| Key | Action |
|---|---|
| `Ctrl` + `Z` | undo |
| `Enter` | close a free shape |
| `Esc` | cancel the current action |
| `Alt` | switch snapping off for one move |
| `Shift` | keep a free wall straight |
| `?` | open the sheet of keys |
| right-click or long-press | pin a [note](plan-tools.md#notes) |

## This documentation

| Key | Action |
|---|---|
| `Ctrl` + `K` or `/` | search |
| `↑` `↓` `Enter` | choose and open a result |
| `Esc` | close the search |
